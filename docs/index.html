    Кіно-Вікторина (Quiz-app)

    Кіно-Вікторина — це професійний навчальний проєкт, розроблений для демонстрації навичок створення сучасних React-додатків з використанням Zustand, TypeScript та Storybook.

    Мета проєкту (Purpose)

    Цей проєкт був створений для вирішення наступних завдань:

    • Ефективне керування станом: Використання Zustand як легкої альтернативи Redux Toolkit.

    • Компонентна ізоляція: Розробка інтерфейсу через Storybook для забезпечення перевикористання коду.

    • Типізація: Забезпечення стабільності коду через строгу типізацію TypeScript.

    • Автоматизація: Налаштування CI/CD процесів через Husky та автоматичну генерацію документації.

    Налаштування гри

    Перед початком гри ви можете налаштувати параметри під свій рівень:

    Налаштування Опис Діапазон
    Кількість питань Скільки запитань буде у вікторині 1–15
    Складність Рівень складності питань Легка / Середня / Складна / Всі
    Час на відповідь Скільки секунд дається на одне питання 5–60 сек

    Детальніше про складність:

    • Легка — загальновідомі факти про популярні фільми
    • Середня — питання для справжніх кіноманів
    • Складна — для експертів, які знають деталі та історію кіно
    • Всі — випадкові питання різного рівня

    Правила гри

    1. Старт: Натисніть кнопку "Почати гру" на головному екрані після вибору налаштувань.
    2. Таймер: На кожне питання відведено час, який ви обрали в налаштуваннях.
      • Якщо час спливає — питання автоматично пропускається.
      • Після вибору відповіді таймер зупиняється.
    3. Відповіді: Оберіть одну правильну відповідь із 4 варіантів.
      • Правильна відповідь — +100 балів
      • Неправильна відповідь — 0 балів
      • ️ Пропущене питання — 0 балів
    4. Прогрес: Відстежуйте поточне питання та кількість набраних балів.
    5. Результат: Після завершення всіх питань ви побачите:
      • Загальний рахунок
      • Кількість правильних/неправильних/пропущених відповідей
      • Відсоток успішності
      • Історію всіх ігор

    Встановлення

    Клонування репозиторію

    git clone https://github.com/MariaVlod/quiz-game.git

    Встановлення залежностей

    npm install

    Запуск у режимі розробки

    npm run dev

    Документація (Documentation)

    Повна документація доступна у двох форматах:

    1. Локально: Згенеровані TypeDoc файли знаходяться у папці /docs.
    2. Онлайн: Ви можете переглянути документацію прямо в браузері: ВІДКРИТИ ОНЛАЙН ДОКУМЕНТАЦІЮ

    Структура проєкту

    Архітектура проєкту побудована за модульним принципом:

    my-quiz-app/
    ├── src/
    │   ├── components/          # React компоненти
    │   │   ├── Button/          # Універсальна кнопка
    │   │   ├── Card/            # Картка контейнер
    │   │   ├── Header/          # Заголовок з навігацією
    │   │   ├── Modal/           # Модальне вікно
    │   │   ├── SettingsForm/    # Форма налаштувань
    │   │   └── CookieConsent/   # GDPR Cookie popup
    │   │
    │   ├── pages/                # Сторінки додатку
    │   │   ├── StartPage/        # Головна сторінка з налаштуваннями
    │   │   ├── GamePage/         # Сторінка гри
    │   │   ├── ResultPage/       # Сторінка результатів
    │   │   ├── UserProfilePage/  # Профіль користувача
    │   │   └── UsersListPage/    # Список користувачів
    │   │
    │   ├── game/                  # Ігрові компоненти
    │   │   ├── Question/          # Текст питання
    │   │   ├── AnswerList/        # Список відповідей
    │   │   ├── AnswerOption/      # Окремий варіант відповіді
    │   │   ├── ProgressInfo/      # Індикатор прогресу
    │   │   └── ScoreBoard/        # Табло рахунку
    │   │
    │   ├── store/                  # Zustand стейт-менеджмент
    │   │   └── gameStore.ts        # Глобальний стан
    │   │
    │   ├── hooks/                   # Кастомні хуки
    │   │   ├── useQuizData.ts       # Завантаження питань
    │   │   ├── useGameFlow.ts       # Логіка гри
    │   │   ├── useTimer.ts          # Таймер
    │   │   └── useResults.ts        # Обробка результатів
    │   │
    │   ├── types/                    # TypeScript типи
    │   │   └── index.ts
    │   │
    │   ├── routes/                    # Маршрутизація
    │   │   └── AppRouter.tsx
    │   │
    │   ├── data/                      # Мок-дані
    │   │   └── mockQuestions.ts       # Питання про фільми
    │   │
    │   ├── styles/                     # Глобальні стилі
    │   │   └── index.css
    │   │
    │   ├── App.tsx                     # Кореневий компонент
    │   └── main.tsx                    # Точка входу
    │
    ├── docs/                           # Згенерована документація
    ├── .storybook/                     # Storybook конфігурація
    ├── public/                          # Статичні файли
    ├── LICENSE                          # Ліцензія MIT
    ├── PRIVACY_POLICY.md                # Політика конфіденційності
    ├── EULA.md                          # Угода з користувачем

    Що включено (What's Included)

    Проєкт містить повний набір інструментів для розробки та аналізу:

    • Game Core: Компоненти Question та AnswerList для керування ігровою логікою.

    • UI-Kit: Документовані компоненти в Storybook.

    • Compliance: Модулі згоди на використання Cookies та вбудована Політика конфіденційності.

    • Reports: Автоматично згенеровані звіти про ліцензії використаних бібліотек (JSON/CSV).
