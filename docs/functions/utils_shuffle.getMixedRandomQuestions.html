    Function getMixedRandomQuestions

    • getMixedRandomQuestions(allQuestions: Question[], count: number): Question[]

      Отримує випадкові питання з усіх доступних, незалежно від складності. Перемішує всі питання і повертає вказану кількість.

      Parameters

      • allQuestions: Question[]

        Масив всіх доступних питань

      • count: number

        Бажана кількість питань

      Returns Question[]

      Масив випадкових питань з різною складністю

      Example

      const allQuestions = [
        { id: '1', text: 'Питання 1', difficulty: 'easy', options: [] },
        { id: '2', text: 'Питання 2', difficulty: 'medium', options: [] },
        { id: '3', text: 'Питання 3', difficulty: 'hard', options: [] }
      ];
      getMixedRandomQuestions(allQuestions, 2); 
      // Повертає 2 випадкових питання з будь-якою складністю

      Example

      getMixedRandomQuestions([], 5); // Повертає порожній масив

      See

      shuffleArray Використовує цю функцію для перемішування
